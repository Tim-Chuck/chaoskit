# ChaosKit 演示脚本

1. **基线。** 打开订单页，确认订单号和商品能正常显示。
2. **注入。** 在面板创建 `GET /api/orders/1` 的 HTTP 500 规则，保存后立即生效。
3. **复现。** 重新打开旧版，浏览器已经收到 500，页面仍停在加载中。
4. **恢复。** 打开修复版，确认错误提示和重试按钮可见。恢复接口，点击重试，观察新的 GET 返回 200 后订单重新出现。
5. **验收。** 运行 `python -m chaoskit check --samples 250,650`，打开 HTML 报告，展示采样时间、页面截图和分项结果。说明四个对照页三轮测试的分数依次为 100、80、50、0。
